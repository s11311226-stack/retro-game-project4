# 《無名校區》(Unnamed Campus) — 體驗版 (Demo v0.4.0)

使用 **Phaser 3 + TypeScript + Vite** 開發的 2D 側視橫向探索懸疑恐怖 RPG。
體驗版章節：**「點名簿上不存在的人」**。

---

## 1. 安裝、啟動、建置與測試說明

### 環境需求
- **Node.js**：`v18+`（本機驗證版本 `v24.20.0`）
- **npm**：`v9+`（本機驗證版本 `11.19.0`）

### 常用指令

```powershell
# 1. 安裝專案依賴
npm install

# 2. 啟動本機開發伺服器 (預設 http://localhost:5173)
npm run dev

# 3. 執行 TypeScript 嚴格型別檢查
npm run typecheck

# 4. 執行自動化測試套件 (Vitest)
npm test

# 5. 執行正式生產環境打包建置 (輸出至 dist/)
npm run build

# 6. 預覽生產環境打包成果
npm run preview
```

## 3. 各階段完成功能總覽

### Phase 1 — 玩家控制與 2D 側視遊戲核心
- **像素風格整數倍縮放**：採用 `640×360` 邏輯解析度，搭配 `Phaser.Scale.FIT` 與 CSS `image-rendering: pixelated`。
- **128×128 畫布基準與獨立碰撞箱**：角色基準畫布為 `128×128`，物理碰撞箱獨立設為 `28×64`，不直接使用整張精靈圖作為碰撞範圍。
- **角色動作與戰鬥狀態機**：涵蓋待機 (`idle`)、移動 (`move`)、跳躍 (`jump`)、攻擊 (`attack`：起手 `startup`、有效判定 `active`、收招 `recovery`、冷卻 `cooldown`) 與格擋 (`block`)。
- **失焦保護**：視窗失焦 (`blur`) 或切換分頁時自動重置所有按鍵與滑鼠狀態。

### Phase 2 — 校門、走廊、教室、公告欄區域與互動系統
- **四大獨立探索區域**：
  1. **校門 (`SchoolGateScene`)**：閱讀「入學通知」，前往公告欄或校園走廊。
  2. **公告欄區域 (`BulletinAreaScene`)**：調查「公告欄」、閱讀「失蹤學生海報」、拾取「生鏽的三年丙班鑰匙」。
  3. **校園走廊 (`CorridorScene`)**：調查「走廊歷史沿革碑」、使用鑰匙解鎖「三年丙班教室門」。
  4. **教室 (`ClassroomScene`)**：調查第 30 號「課桌」、「黑板」、拾取「刻有校徽的黃銅名牌」及閱讀「神祕校務文件」。
- **互動一致性保證**：同一時間只允許一個主要互動視窗；已拿取物品在同一存檔中絕不重複生成；文件可無限次重複閱讀但不會重複新增同一條線索；切換場景自動執行安全落地座標校正。

### Phase 3 — 體驗版短篇劇情「點名簿上不存在的人」與結尾
- **完整體驗版敘事閉環**：
  - 開始時於校門播放入學演出，結束後交還控制權。
  - 比對公告欄的「失蹤學生海報」（林曉月）與教室內日期早於建校日（1998 年 vs 2004 年）的「神祕校務文件」。
  - 完成調查後觸發溫和的視覺閃爍與低頻懸疑音效，文件浮現**「新生已完成觀察」**訊息，隨後進入體驗版通關結算畫面並支援重新開始。
- **未來系統擴充介面**：預留證據完整度、NPC 好感度、財閥警戒度與多結局評估介面 (`IMultiEndingExtensionHooks`)。

### Phase 4 — 體驗版品質整理、存檔系統與音訊設定
- **版本化存檔系統 (`SaveManager`, `schemaVersion: 2`)**：
  - 儲存玩家所在區域、座標、朝向、已拾取物件 ID、背包物品、已讀線索與劇情旗標。
  - 具備損毀 JSON 攔截、缺漏欄位檢查、舊版本 (`v1` -> `v2`) 自動遷移，以及禁止寫入密碼／權杖等機密欄位的安全檢查。
  - 支援過場自動存檔、暫停選單手動存檔／讀取存檔，以及主選單「讀取存檔繼續」與「開始新遊戲」。
- **主選單與原創程序化音訊系統 (`MainMenuScene`, `AudioSynthManager`)**：
  - 嚴格遵守瀏覽器首次互動解鎖規範（首次點擊或按鍵前不強制自動播放）。
  - 內建原創可循環播放的懸疑校園背景音樂 (Looping Ambient BGM) 與 7 類完整音效（腳步、跳躍、攻擊、格擋、互動/拾取、開門、神祕訊息演出），並提供獨立的 BGM / SFX 音量調整與靜音切換。
