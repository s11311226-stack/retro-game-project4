### 01. 蘇語晴 (Su Yu-Qing) — 主角
- **身分背景**：17 歲，高三轉學生。為了尋找半年前在白川學園離奇失聯、被校方宣稱「自願退學出國」的雙胞胎姊姊蘇語嵐，隱瞞親屬關係轉入三年丙班。
- **外貌與服裝方向（128×128 像素）**：深黑色及肩短髮，左側別著姊姊留下的銀色雙燕髮夾；身穿深藏青色冬季水手服與百褶裙，肩背棕色舊書包，手持可照射暗處的手電筒與防身短棍。
- **性格**：冷靜敏銳、重情重義，面對威權與怪異現象時展現出極強的心理韌性。
- **個人秘密**：與姊姊蘇語嵐存在罕見的「雙胞胎腦波共鳴」，對 `18.9Hz` 次聲波具備半免疫體質，但過度接觸實驗設備時會聽見姊姊的求救幻聽。
- **劇情定位**：玩家操作角色。連接地面學生群體與地下真相的唯一樞紐。
- **與主角的關係**：玩家自身。
- **角色支線**：《雙燕的回音》——收集散落於宿舍、禁書室與 B1 的蘇語嵐五段錄音日誌，拼湊姊姊失蹤當晚的完整路線。
- **好感度及信任度影響**：其對話抉擇直接決定全體學生的 `studentAffinity` 與 `studentTrust` 成長幅度。
- **可能的結局影響**：
  - 高證據 + 高曝光 → 導向 **A 結局（真相大白）**。
  - 高學生信任 + 高親和 + 低創傷 → 號召全校與家長達成 **C 結局（群體反抗／攻佔結局）**。
  - 實驗侵蝕度過高 → 淪為 **D 結局（無名者）** 或觸發 **E 結局（觀察者）**。
