# 《無名校區》(Nameless Campus) — 美術指導規範 (ART DIRECTION)

- **文件版本**：v1.0 (Production Phase 5)
- **核心規格**：`640×360` 邏輯解析度（16:9 像素整數倍縮放） / `128×128` 角色像素畫布基準

---

## 一、視覺風格定位 (Visual Pillars)

1. **高對比懸疑像素美學 (Atmospheric Pixel Noir)**：
   - 以冷調深藍、鐵灰與墨綠構築壓抑的寄宿學校日常；當夜間「第四聲鐘響 (`18.9Hz`)」或「認知過濾」發作時，切入刺目的暗紅、琥珀黃與螢光幽綠（B3 回聲搖籃）。
2. **128×128 精細角色動態與獨立碰撞箱**：
   - 所有角色精靈圖統一採用 **`128×128` 像素畫布基準**，給予髮絲、制服皺褶、手持燈光、武器揮擊弧線充足的表現空間。
   - **物理與視覺分離鐵則**：角色的實際物理碰撞箱固定為中央底部的 **`28×64` 像素**（`offsetX: 50, offsetY: 64`），絕不以整張 `128×128` 畫布作為碰撞範圍。
3. **無縫替換轉接架構 (`ICharacterVisualAdapter` / `IInteractableVisualAdapter`)**：
   - 開發階段的占位像素圖形必須清楚標示結構、朝向與互動狀態，並透過統一介面隨時可替換為正式 SpriteSheet 與 Tilemap 圖層。

## 三、角色動畫狀態與 128×128 幀數規範

主角（蘇語晴）與主要 NPC／敵人於 `128×128` 畫布下的標準動畫序列規範：

1. **`idle`（待機）**：4 幀循環（呼吸起伏與髮絲微動，每幀 180ms）。
2. **`move`（移動／奔跑）**：6～8 幀循環（明確的左右腳步交替，配合第 2、5 幀觸發腳步音效）。
3. **`jump`（跳躍與滯空）**：上升 2 幀、滯空 1 幀、落地緩衝 1 幀。
4. **`attack`（防身揮擊）**：
   - `startup`（起手蓄力，90ms）：2 幀，身體後傾、武器舉起並顯示黃色預警高光。
   - `active`（有效判定，120ms）：2 幀，大幅度向前揮擊弧線，僅在此幀區間啟用 `42×36` 攻擊判定框。
   - `recovery`（收招後搖，140ms）：2 幀，重心收回。
5. **`block`（格擋架勢）**：2 幀，雙手橫舉防身棍或護具於身前，受擊時產生火花粒子。
6. **`stealth`（夜間蹲伏／掩體躲藏）**：2～4 幀，壓低身形並縮小手電筒光束角度。

## 四、UI 介面與視覺特效安全規範

1. **像素字體與清晰度**：
   - 全面採用等寬像素風格字體排版，對話框、文件閱讀器 (`DocumentModal`) 與背包 (`InventoryModal`) 皆使用高對比深色底板 (`#090d16` 搭配 `#fcd34d` 標題與 `#f8fafc` 內文)，確保在 `640×360` 解析度下字跡銳利清晰。
2. **光敏感與可讀性保護（Anti-Photosensitivity Rule）**：
   - 在表現「18.9Hz 第四聲鐘響」與「新生已完成觀察」畫面閃爍時，嚴格限制遮罩最高不透明度 `alpha <= 0.28`，且單次閃爍頻率低於 `3Hz`，杜絕強烈白光頻閃或遮蔽文字閱讀。
3. **跨平台行動端 UI 預留**：
   - 畫面左下角與右下角 `80px` 邊緣區域預留給 Android／iOS 打包時的虛擬方向鍵與 `[互動 E]`、`[攻擊]`、`[格擋]` 觸控按鈕，避免關鍵文字被手指遮擋。
