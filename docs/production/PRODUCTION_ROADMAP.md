## 二、正式版後續開發階段規劃 (Phases 6A – 10)

---

### Phase 6A — 核心系統與資料層擴充（變數、角色關係、證據與存檔升級）
- **開發目標**：
  1. 實作 8 大正式版核心變數管理（`evidenceCompletion`, `injuryCount`, `studentAffinity`, `studentTrust`, `corporateAlert`, `experimentCorruption`, `publicExposure`, `academicCredits`）。
  2. 建立 `CharacterRelationshipSystem`（15 位角色資料庫與好感/信任雙軸計算）。
  3. 建立 `EvidenceSystem`（含錯誤線索識破機制）與 `QuestSystem`（主線與支線狀態追蹤）。
  4. 擴充 `SaveManager` 支援多存檔槽位（Slot 1～3 + AutoSave）及正式版欄位，同時 **100% 向下相容現有 Demo V2 存檔**。
- **驗收標準**：既有 23 項測試全數通過，並新增 Phase 6A 系統單元測試。

---

### Phase 6B — 完整 14 區域校園與地下實驗室地圖擴充
- **開發目標**：
  1. 在保留既有 4 區（校門、公告欄、走廊、教室）的基礎上，新增其餘 10 個正式版可探索區域：
     - 地面新增：**教務處、教師辦公室、宿舍、舊圖書館、禁書室、頂樓、保健室**。
     - 地底新增：**地下 B1（檢體篩選區）、地下 B2（認知過濾中樞）、地下 B3（回聲搖籃核心）**。
  2. 實作日夜雙軌時段切換（日間課堂／黃昏 `18.9Hz` 第四聲鐘響／夜間封鎖探索）與 `AcademicSystem`。
- **驗收標準**：驗證全部 14 個區域的雙向出入口切換、門禁條件與安全落地座標（絕不卡牆或懸空）。

---

### Phase 7 — 潛行、敵人 AI、防身戰鬥與 18.9Hz 認知侵蝕系統
- **開發目標**：
  1. 實作 `StealthSystem`（視野錐偵測、掩體躲藏、聲響吸引）與 `Enemy AI`（夜間巡邏守衛、B1 陳孟哲、B2 失控實驗體、B3 白川鏡花防衛機制）。
  2. 實作 `CombatSystem`：串接 `PlayerController` 的有效攻擊判定框 (`getActiveAttackHitbox`) 與格擋減傷，處理 `injuryCount` 與 `experimentCorruption` 累積與治療。
  3. 實作陸子軒的「18.9Hz 逆相抗頻音叉」互動機制。
- **驗收標準**：自動化測試覆蓋 AI 狀態轉換、潛行掩體判定、攻擊命中與格擋減傷邏輯。

---

### Phase 8 — 四大章節完整劇本、15 角色互動與五種結局實作
- **開發目標**：
  1. 實作第一章《第29張課桌》至第四章《第四聲鐘響之後》的完整主線、角色支線對話分支與錯誤線索比對。
  2. 實作 `EndingEvaluator` 與 **A / B / C / D / E 五種結局完整演出**。
  3. **重點實作 C 結局（群體反抗／攻佔結局）**：完整實作校門口集結並依序攻佔 **「校門 → 公告欄 → 走廊 → 教室 → 教師辦公室 → 宿舍 → 舊圖書館 → 頂樓 → 保健室 → 地下 B1 → B2 → B3」** 的 12 站推進流程。
- **驗收標準**：透過自動化測試驗證全部 5 種結局的觸發公式、優先序以及 C 結局 12 站推進無軟鎖。

---

### Phase 9 — 128×128 像素視覺精修、音訊強化與跨平台（Android/iOS）適配
- **開發目標**：
  1. 升級 15 位角色的 `128×128` 像素動態與對話立繪、14 區域背景細節及日夜／認知異常視覺濾鏡。
  2. 擴充 `AudioManager` 的 7 首原創循環 BGM 與 `18.9Hz` 心理聲學拍頻鐘聲。
  3. 加入行動端響應式虛擬觸控按鈕層（Virtual Touch Pad）與 Capacitor/Cordova 打包設定預留，並優化 Vite `manualChunks` 分包。

---

- **開發目標**：
  1. 執行完整單元測試、整合測試、TypeScript 嚴格檢查與 Vite 正式建置。
  2. 完成正式版說明文件與發布報告，經使用者確認後執行 Git Commit 與 GitHub 同步。
