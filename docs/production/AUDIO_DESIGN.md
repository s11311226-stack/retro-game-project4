## 一、核心聲學概念：「18.9Hz 第四聲鐘響」的心理聲學轉譯

在世界觀中，白川財閥利用 **`18.9Hz` 次聲波**誘發學生視覺鬼影與記憶覆寫。由於一般消費級喇叭與耳機難以直接重現低於 `20Hz` 的純物理次聲波，遊戲音訊系統採用**「雙耳拍頻與低頻泛音轉譯（Harmonic & Binaural Translation）」**技術：

1. **第一至第三聲鐘響（正常報時）**：
   - 以 `440Hz (A4)` 疊加 `880Hz` 鐘琴泛音呈現標準校園下課鐘聲。
2. **第四聲鐘響（18.9Hz 異常調變）**：
   - 基頻瞬間下潛至可聽見的深沉次低音 **`56.7Hz`（即 `18.9Hz × 3` 三次諧波）** 與 **`75.6Hz`（`18.9Hz × 4` 四次諧波）**，兩者之間的差頻正好在人耳內產生 **`18.9Hz` 的心理聲學拍頻脈衝（Beat Frequency）**！
   - 讓玩家在普通耳機或喇叭上也能清晰感受到每秒約 19 次的低頻空間震顫與懸疑壓迫感，同時保證聽覺安全。

## 二、背景音樂 (BGM) 曲目規劃

所有背景音樂皆支援無縫循環播放（Looping）與獨立音量控制 (`bgmVolume: 0.0 ~ 1.0`)：

| 曲目編號與名稱 | 適用場景 / 時段 | 調性與配器方向 | 情緒氛圍 |
| :--- | :--- | :--- | :--- |
| **BGM-01：《霧谷的入學式》** | 主選單 (`MainMenuScene`)、校門日間 | A 小調，緩慢分解鋼琴與大提琴長音 | 孤寂、神祕、山霧瀰漫的宿命感 |
| **BGM-02：《二十八人的日常》** | 日間走廊、教室、公告欄、宿舍 | C 大調轉 A 小調，木管與微失諧音樂盒 | 表面平靜卻隱約透出違和感 |
| **BGM-03：《守書人的提燈》** | 舊圖書館、禁書室、許文謙支線 | D 小調，古典魯特琴／鋼琴慢板 | 沉穩、知性、暴風雨前的庇護所 |
| **BGM-04：《第四聲鐘響之後》** | 夜間全校區探索、教務處潛行 | 減五度三全音音程 + `18.9Hz` 諧波低音脈衝 | 壓迫、緊張、隨時可能被發現的懸疑感 |
| **BGM-05：《回聲搖籃 (Echo Cradle)》** | 地下 B1～B3 探索與白川鏡花對峙 | 電子合成器 Drone + 空靈女聲合唱取樣（雙子共鳴） | 冰冷、科幻恐怖、神聖又扭曲的實驗場 |
| **BGM-06：《第29號的反擊》** | C 結局（12 區域依序攻佔）、B3 最終決戰 | 高節奏小軍鼓進行曲 + 激昂弦樂與逆相鐘聲 | 熱血、團結、衝破黑暗的史詩感 |
| **BGM-07：《黎明或遺忘》** | 五大結局結算畫面（依結局切換和弦色彩） | A/C 結局為溫暖大調；B/D/E 為冷冽殘響 | 釋懷、悲壯或餘音繞樑的毛骨悚然 |

## 三、環境音與動作音效清單 (SFX Matrix)

音效系統受 `sfxVolume (0.0 ~ 1.0)` 與 `muted` 控制，完整涵蓋以下類別：

| 類別 | 音效名稱 | 對應方法 / 事件 | 聲音特徵設計 |
| :--- | :--- | :--- | :--- |
| **角色動作** | 走廊/地面腳步聲 | `playFootstep()` | 依地面材質微調的低頻三角波短促敲擊（附 250ms 節流） |
| **角色動作** | 跳躍與落地聲 | `playJump()` | 向上滑音與衣料摩擦聲 |
| **防身戰鬥** | 揮擊破空聲 | `playAttack()` | 鋸齒波快速下潛的短棍破空音效 |
| **防身戰鬥** | 格擋架盾聲 | `playBlock()` | 方波金屬/硬木撞擊共鳴聲 |
| **環境互動** | 調查 / UI 確認 | `playUiClick()` | 清脆的打字機/紙張翻動點擊音 |
| **環境互動** | 關鍵物品拾取 | `playItemPickup()` | 四度上行雙音提示（440Hz → 660Hz） |
| **環境互動** | 推開木門 / 鐵門 | `playDoorOpen()` | 低頻門軸轉動與門鎖咔噠聲 |
| **劇情演出** | 18.9Hz 第四聲鐘響 | `playFourthBellChime()` | 三聲正常鐘響後接續深沉的 18.9Hz 差頻共鳴長音 |
| **劇情演出** | 認知異變 / 觀察完成 | `playAnomalyGlitchStinger()` | 不協和半音群（110Hz / 116.5Hz / 233Hz）疊加類比雜訊 |
| **劇情演出** | 逆相音叉啟動 | `playCounterPhaseChime()` | 880Hz 清澈高頻泛音，瞬間抵消環境低頻嗡鳴 |
